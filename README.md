Project: Space Invaders - Year 9 Computing Technology
How to start the project
1. Install Python 3 from the official Python website if it is not already installed.
2. Open the project folder in Visual Studio Code.
3. Open the integrated terminal.
4. Install Pygame using: pip install pygame
5. Save the Appendix code as main.py.
6. Run: python main.py
7. Press Enter or Space on the menu screen.
Controls
A / Left Arrow - move left
D / Right Arrow - move right
Space - shoot / start game
R - restart after game over
Esc - quit
Files
main.py - game source code
README.md - setup and controls
design/ - exported UML, flowchart and GUI images (optional)
screenshots/ - evidence of testing (optional)
Testing checklist
Player cannot move outside the screen.
Player shooting cooldown works.
Invaders reverse and move downward at screen edges.
Player bullets remove invaders and add score.
Enemy bullets reduce lives.
Shields absorb hits and eventually disappear.
Destroying all invaders creates a new wave.
Game over appears when lives reach zero or invaders reach the bottom.
Restart works without reopening the program.
